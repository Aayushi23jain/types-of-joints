# Terminology and textbook alignment

Written for: subject teachers and translators reviewing the game's text.

All learning text is in `assets/text/strings.json`. Content follows **NCERT Class 6 Science, Ch 8 "Body Movements"** (the previous NCERT book; the new NCF-2023 "Curiosity" books for Classes 6–8 no longer have a joints chapter). Each language uses the terms of its state textbook where one exists.

## What the game teaches (NCERT)
- A joint is a place where two bones meet; we can bend or move only at joints.
- Four joints only: **ball and socket** (shoulder, hip: rounded end of one bone in the hollow of another; all directions), **pivotal** (where the neck joins the head: a cylindrical bone turns in a ring; head bends forward/back and turns left/right), **hinge** (elbow, knee: only back and forth, like a door hinge), **fixed** (skull bones, upper jaw and the rest of the head: no movement).
- Not taught (removed): the immovable / slightly movable / freely movable grouping and gliding joints. Both are Class 11 Biology content.
